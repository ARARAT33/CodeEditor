# 12 — Keyboard Shortcuts

Complete reference for all AWECode keyboard shortcuts.

## Customization

To change keyboard shortcuts:
1. Open Settings (`Ctrl+,`)
2. Go to **Keyboard Shortcuts**
3. Search for the command
4. Click to edit, press the new key combination
5. Press `Enter` to save

Or edit `~/.awecode/keybindings.json` directly (VS Code-style format).

## Tips

- Most shortcuts match VS Code exactly — muscle memory transfers
- Use the command palette (`Ctrl+Shift+P`) to discover commands and their shortcuts
- Hold `Ctrl` (Windows/Linux) or `Cmd` (Mac) for most editor shortcuts
- Hold `Alt` (Windows/Linux) or `Option` (Mac) for line/cursor operations
- Hold `Shift` to extend selections
