## Language Auto-Detection

AWECode auto-detects the language from the file extension when you open a file. Special filenames are recognized:
- `Dockerfile` → Dockerfile
- `Makefile` → Makefile
- `CMakeLists.txt` → CMake
- `.gitignore` → gitignore
- `.env*` → env

You can also override the language manually using the language selector in the top toolbar.

## Adding a New Language

To add a new language:

1. Edit `src/lib/awecode/languages.ts`
2. Add a new entry to the `LANGUAGES` array:
```typescript
{
  id: 'mylang',
  label: 'My Language',
  extensions: ['.myl'],
  monacoId: 'plaintext',  // or register a custom Monaco language
  category: 'Other',
  hasLinter: false,
  hasVulnScan: false,
}
```
3. If the language has a Monaco language ID, syntax highlighting will work immediately
4. To add linter rules, edit `src/lib/awecode/linter.ts` and add rules with `'mylang'` in the `languages` array
5. To add vulnerability rules, edit `src/lib/awecode/vulnerabilities.ts`
